先用简体中文写简短的 reasoning，说明图片和文字中支持评价的可见依据；不要编造缺失细节。
再根据上述评价自行给出 0–9 分的 rating，可以使用小数。
只输出一个合法 JSON 对象，恰好包含两个字段，顺序为 reasoning（字符串）、rating（数字）。不要输出 Markdown 或 JSON 之外的文字。
以下仅为格式示例，理由和分数必须根据实际输入确定，不要照抄：
{"reasoning": "图片与文字描述基本一致，但部分细节缺少视觉支持。", "rating": 6}
